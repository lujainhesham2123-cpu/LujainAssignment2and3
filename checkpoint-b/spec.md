## What you are building

A small page, in three files you write yourself:

| File | What it holds |
|---|---|
| `checkpoint-b/page.html` | the structure |
| `checkpoint-b/page.css` | the styling |
| `checkpoint-b/page.js` | the behaviour |

The data is given to you in `checkpoint-b/items.js`, which you import. Do not
edit it, and do not copy the items into your own files.

```js
import { items } from "./items.js";
```

Every item looks like:

```js
{ id: 1, name: "Notebook", category: "stationery", price: 45, inStock: true }
```

## 1. `page.html`

- A `<!DOCTYPE html>` and a `<html lang="en">`.
- In the head: a `<meta charset="UTF-8">`, a `<title>` — any text you like —
  and a `<link>` to your `page.css`.
- An `<h1>` whose text is exactly:

  ```
  The Corner Shop
  ```

- A `<ul>` or `<ol>` with `id="list"`. **Leave it empty** — JavaScript fills it.
- A `<button>` with `id="apply"` whose text is exactly:

  ```
  Apply filter
  ```

- A `<script>` that loads your `page.js`. Because `page.js` uses `import`,
  the tag needs `type="module"`:

  ```html
  <script type="module" src="page.js"></script>
  ```

## 2. `page.css`

- A rule for `body` that sets a `font-family` and a `background-color`.
- A rule for `.entry` — the class your list items carry — that sets
  `padding` and `color`.
- The text has to be **readable**: your `.entry` colour needs a contrast
  of at least 3:1 against the background behind it. The tests check this.

## 3. `page.js`

Export three functions.

### `renderItems(list)`

Draws an array of items into `#list`, replacing whatever was there.
Each item becomes an `<li>` with:

- the class `entry`, and
- its text in exactly this shape:

  ```
  {name} - {price} EGP
  ```

  so the Notebook (45 EGP, stationery) comes out as:

  ```
  Notebook - 45 EGP
  ```

Called again with a different array, it replaces the old items rather than
adding to them. An empty array leaves the list empty.

### `matching()`

Returns only the items over 100 EGP, as an array of item objects from `items`.

> Keep an item when its `price` is more than 100.

### `start()`

Sets the page up:

1. Draws **all** the items straight away, using `renderItems`.
2. Listens for a click on `#apply`. When it is clicked, the list is
   redrawn with only the items over 100 EGP.
